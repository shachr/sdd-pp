# textkit

Small text utilities: turning titles into slugs and laying text out in lines.

## Language

**Line width**:
The maximum number of characters on one output line, not counting the line break.
_Avoid_: column, line length

**Word**:
A run of characters other than spaces, tabs and line breaks.
_Avoid_: token

**Paragraph**:
One line of the input text, as separated by a line break; it is wrapped on its own.
_Avoid_: block
